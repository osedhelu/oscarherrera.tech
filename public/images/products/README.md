# Imágenes de productos

Coloca aquí las imágenes de cada producto del marketplace.

- **Nombres:** Deben coincidir con `imageUrl` en `data/products.ts` (ej. `curso-solidity.png`, `membresia.png`, `plantilla-web3.png`).
- **Formato:** PNG, WebP o JPG. Tamaño recomendado: 350×350 a 1000×1000 px.
- El JSON de metadata del NFT usará la URL absoluta de estas imágenes para que wallets y OpenSea las muestren.
